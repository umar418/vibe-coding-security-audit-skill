## 1.0.0 (2026-11-20)

First public release.

- `SKILL.md` with the six-step audit workflow, in the open Agent Skills format for Claude Code, OpenAI Codex and compatible agents.
- 19-category security checklist (`references/checklist.md`), based on the OWASP Top 10 and extended for AI-built apps, including an AI/LLM-specific section.
- Stack-specific notes for Next.js/Vercel, Supabase, Firebase, Node/Express and WordPress/PHP.
- Report template and a complete example report.
- `scripts/quick_scan.sh`: a dependency-free grep-based first-pass scanner.
